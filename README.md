# Agent Platform Cookbook 🏛️

> 企业级智能体管控平台的实战模式库——多框架纳管、渠道接入、能力治理的踩坑与解法。

作者在某头部券商信息技术部负责智能体管控平台（统一纳管 OpenClaw / ZeroClaw / DeepSeek Harness 等多智能体框架 + 渠道接入服务）。这本 cookbook 把平台建设中验证过的模式整理成可复用的参考架构。**所有内容均已脱敏，不含任何公司内部信息。**

## 这些模式从哪来

每一个模式都来自生产环境的真实需求：

- 业务方今天用 OpenClaw、明天要试 DSH、后天又出一个新框架——**不能每接一个框架就重写一遍接入层**
- 飞书/企微/钉钉/微信的消息模型各不相同——**渠道差异必须收敛在一层**
- 金融场景的合规与审计要求——**每一次调用都要可追溯、可管控、可降级**

## 适合谁

- 正在建设企业内部 Agent 平台的工程师/架构师
- 需要给多套 Agent 框架做统一接入的团队
- 关注智能体治理（governance）的技术管理者
